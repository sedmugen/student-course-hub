# 2. Overall Description

## 2.1 Product Perspective

SmartCourseHub is a **new web application**, not replacing an existing one (in case study). It has:

- **Presentation Layer**: ReactJS SPA
- **Business Layer**: Spring Boot REST services
- **Data Layer**: Spring Data JPA + MySQL

## 2.2 User Classes & Roles

### Admin
- Manage users, courses, programs, sections

### Instructor
- Manage attendance, assignments, grades

### Student
- Manage enrollments, view schedule, marks, transcript

## 2.3 Operating Environment

- **Server**: Java 17+, Spring Boot 3.x
- **Database**: MySQL 8+
- **Client**: Modern browser (Chrome/Edge/Firefox)
