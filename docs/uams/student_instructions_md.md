# Final TERM EXAM — STUDENT INSTRUCTIONS

**Course:** Web Engineering  
**Duration:** 2 Hour (120 Minutes)  
**Mode:** Laptop-Based Exam  
**Resources:** Internet / Online Resources Allowed  
**Post-Exam:** Viva + Evaluation + Code Submission

---

## 📝 Important Instructions (Read Carefully)

### 1. Exam Duration & Format

- **Total duration** of the written/practical exam: **1 Hour (60 minutes)**
- You will work on your laptop during the exam.
- You may use Java, Spring Boot, Spring Data JPA, Postman, and any IDE (IntelliJ, Eclipse, VS Code).

### 🌐 2. Internet & External Resources

**Online resources ARE allowed** (open-book style exam).

You may search on:
- StackOverflow
- Spring Boot documentation
- Baeldung
- GeeksForGeeks
- ChatGPT

**HOWEVER:**
- Copy-pasting answers is **NOT allowed**.
- Your code must be written in **your own words and structure**.
- During viva, you **must explain your own code** — otherwise marks will be deducted.

### 🚨 3. Academic Integrity Rules

This is an **individual exam** — no collaboration allowed.

**You may not:**
- Share code
- Send screenshots
- Help another student
- Allow anyone else to write your code

AI-generated answers without your understanding will be caught during viva.

### 💻 4. What You Must Implement

During the exam, you will complete tasks based on:

- ✔ Spring Boot
- ✔ Spring Data JPA
- ✔ Entities & Relationships
- ✔ Repository + Service + Controller
- ✔ REST APIs
- ✔ JSON Payloads
- ✔ Postman Testing

Tasks must follow the **ERD provided in the exam**.

### 🎤 5. Viva & Evaluation (After Exam)

After the written exam:

You will undergo a **compulsory Viva (Oral Examination)**. The instructor will ask you to:

- Explain your entities, relationships, and annotations
- Justify your APIs and routing
- Demonstrate your Postman calls
- Explain your error handling and logic
- Show your project structure

**Failure to explain your own code = deduction of up to 50% of marks.**

### 📁 6. Final Submission Requirements

After completing the exam and viva:

You must submit a **single Word document (.docx)** containing:

#### A) Source Code (all relevant files)

Copy/paste the full code of:
- All Java files
- Entities
- Repositories
- Services
- Controllers
- `application.properties` / `application.yml`
- Any XML configuration (if used)
- Any JSON request/response samples used

#### B) Student Information

At the top of the DOCX file include:
- Full Name
- Student ID
- Semester & Section
- Date of Submission

#### C) Optional (if implemented)

- Exception handlers
- Model classes
- DTOs
- Postman screenshots

### 📦 7. How to Package the Submission

Your final file must be named like this:

```
<YourID>_<YourName>_Midterm_WebEngineering.docx
```

- Upload the file to the LMS/Classroom as instructed.
- **Late submissions are not accepted.**

### 📊 8. Marking Criteria

Marks will be awarded based on:

| Component | Weight |
|-----------|--------|
| Code Accuracy | 40% |
| API Correctness | 20% |
| JSON Payloads | 10% |
| Understanding (Viva) | 20% |
| Documentation & Submission Quality | 10% |
